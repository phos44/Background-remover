## 1. Постановка задачи

Удаление фона — задача бинарной сегментации переднего плана с выходом в виде альфа-маски (alpha matte). Продуктовое требование: результат должен сохранять контуры объекта, волосы, полупрозрачные и мелкие детали (дырки, просветы) при предсказуемой задержке инференса и потреблении памяти на CPU-инстансе (self-hosted сценарий без обязательного GPU).

## 2. Классические методы (baseline)

Классические алгоритмы рассматривались как исторический baseline и как решение для сильно ограниченных сценариев с контролируемым фоном; для произвольных пользовательских изображений они хрупкие.

| Подход | Сильные стороны | Слабые стороны |
|---|---|---|
| Chroma key / цветовой threshold | Очень быстро, только CPU, детерминированно | Требует контролируемый цвет фона и освещение |
| GrabCut / graph cuts | Хорошо для простых объектов с подсказками пользователя | Нужна инициализация, слабо работает с волосами и низким контрастом |
| Watershed / edge-based сегментация | Интерпретируемо и дёшево | Пересегментирует текстурные изображения |
| Traditional matting c trimap | Точно при наличии trimap | Требует ручного ввода или отдельной генерации trimap |

## 3. Семейства методов на основе глубокого обучения

| Семейство | Примеры | Область применения |
|---|---|---|
| Salient Object Detection | U²-Net, IS-Net | Извлечение одного/нескольких основных объектов переднего плана |
| Portrait matting | MODNet, P3M-Net | Real-time матирование портретов/видео |
| Dichotomous Image Segmentation (DIS) | DIS/IS-Net, FP-DIS, MVANet, BiRefNet, DCENet | Категорийно-независимые высокодетальные маски переднего плана |
| Foundation / interactive matting | SAM-based matting, SAMA, ZIM | Промптируемые или zero-shot сценарии при большем compute-бюджете |
| Коммерческие / source-available модели | BRIA RMBG 1.4 / 2.0 | Product / e-commerce качество, требуется проверка лицензии |

### Ключевые наблюдения по SOTA

- DIS5K формализовал высокоточную dichotomous image segmentation для категорийно-независимого извлечения переднего плана и напрямую применим к задаче удаления фона.
- U²-Net предложил вложенную U-структуру, захватывающую многомасштабный контекст при умеренных вычислительных затратах.
- MODNet работает без trimap и в реальном времени для портретов; отлично для людей, но уже, чем задача произвольных объектов.
- FP-DIS добавляет частотные приоры для восстановления тонких границ на DIS5K.
- MVANet использует multi-view агрегацию и показывает высокую точность/скорость в DIS-подобных задачах.
- BiRefNet нацелен на высокоразрешающую dichotomous-сегментацию с модулями локализации и реконструкции плюс bilateral references; веса доступны на Hugging Face.
- BRIA RMBG 1.4/2.0 — практические модели удаления фона для широких коммерческих категорий изображений; RMBG 1.4 — компактная модель 44.1M параметров, RMBG 2.0 доступна через BRIA/FAL и демо на Hugging Face с коммерческими лицензионными ограничениями.
- SAMA и ZIM показывают направление исследований: объединённая сегментация и матирование или zero-shot matting поверх foundation-моделей сегментации — перспективно, но тяжелее и менее удобно для простого self-hosted приложения.

## 4. Сравнение моделей

| Модель | Точность | Скорость/стоимость | Зрелость | Применимость к проекту |
|---|---|---|---|---|
| GrabCut | Низкая-средняя | Очень низкая, CPU | Стабильна | Только baseline |
| MODNet | Высокая для портретов | Очень быстро | Зрелая | Слишком узкоспециализирована |
| U²-Net (rembg) | Хорошее общее качество | Умеренно на CPU, хороший ONNX-деплой | Очень зрелый Python-пакет | Лучший вариант по умолчанию для локального прод-задания |
| IS-Net / DIS | Более высокое качество границ | Выше стоимость | Research-oriented | Хороший будущий адаптер |
| BiRefNet | SOTA-уровень качества DIS | Выше память/latency, крупнее модель | Сильные открытые веса | Лучший кандидат по качеству при наличии GPU |
| BRIA RMBG 1.4/2.0 | Очень высокое практическое качество | Выше сложность зависимостей/лицензии | Зрелые карточки моделей/сервисы | Хороший enterprise-вариант; лицензионно-чувствителен |
| SAMA/ZIM | Очень высокая/промптируемая | Тяжёлая | Emerging 2025-2026 research | Не идеально для первого прод-релиза |

## 5. Выбранная модель и обоснование

Приложение использует `rembg` с `u2net` по умолчанию.

- стабильная Python-интеграция с ONNX Runtime;
- работает на CPU — приложение доступно на девелоперских машинах без CUDA;
- хорошее качество для генерического извлечения переднего плана;
- меньший операционный риск, чем встраивание крупного research-репозитория напрямую в request path;
- чистая граница адаптера позволяет заменить модель на BiRefNet, RMBG или внешний inference-сервис без изменения API или UI.

Для GPU-продакшена с максимальными требованиями к качеству следующим рекомендуемым адаптером является BiRefNet или BRIA RMBG 2.0 после подтверждения лицензии и требований к latency.

## 6. Известная проблема качества: потеря краёв объекта

При эксплуатации выявлена проблема: алгоритм не всегда корректно детектирует границы объекта и удаляет их вместе с фоном (пропадают тонкие детали, волосы, полупрозрачные области). Основные причины и меры устранения:

### 6.1 Причины

- Жёсткая бинаризация soft-маски U²-Net (threshold 0/255) без мягкой alpha-композиции — обрезает полупрозрачные краевые пиксели.
- Отсутствие alpha matting в вызове rembg (`alpha_matting=False` по умолчанию) — маска получается грубой, без trimap-based уточнения.
- Downscale входа под нативное разрешение сети (320×320) и последующий upscale маски методом ближайшего соседа/билинейно без учёта резкости исходных границ.
- Возможная избыточная эрозия маски в постобработке при попытке «подчистить» шум по краям.

### 6.2 Рекомендуемые меры

- Включить alpha matting в rembg (`alpha_matting=True` с настройкой foreground/background threshold и erode_size) — заменяет жёсткий порог на trimap + closed-form matting.
- Работать с альфа-каналом как с непрерывной величиной 0–255 при композитинге, без ручной бинаризации.
- Апскейлить маску обратно в исходное разрешение бикубической/билинейной интерполяцией, а не nearest neighbor.
- Добавить guided filter (edge-aware refinement) с исходным изображением как guide для более точного прилегания маски к реальным границам.
- В среднесрочной перспективе перейти на BiRefNet/IS-Net как модель с встроенной высокой точностью границ (согласно разделу 5).
- Ввести метрику Boundary IoU/Dice (а не только глобальный IoU) и регрессионный набор сложных изображений (волосы, полупрозрачность, мелкие детали) для контроля деградации качества границ при последующих изменениях.
